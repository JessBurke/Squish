# Squish needs only Python 3.8+ (with tkinter, which python.org Python includes).
# These packages are OPTIONAL. "Install Squish.bat" installs them for you; without
# them Squish uses its own built-in readers.
# extract-msg: reads Outlook .msg files a little better.
extract-msg
# pypdf: reads the text of PDF documents (attachments and the documents folder) better.
pypdf
# cryptography: optional; lets pypdf read AES-secured PDFs (Squish's built-in reader opens
# those that need no password without it).
cryptography
